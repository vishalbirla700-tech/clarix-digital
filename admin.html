Why does Google Analytics show far more users?
GA counts every page visit — including the public landing page, about page, terms, and onepager which require no sign-in.
Firestore (this portal) counts only users who completed Google Sign-In.
The 105 India / 42 US GA users are visitors to index.html — most never clicked Sign In.
Focus: your real conversion metric is Visitors → Sign-ups. Currently very low — push people to sign in.

⚠️ Danger Zone
Irreversible operations — proceed with caution
🔄 Bulk Reset All Free User Trials
Resets the trial count to 0 for ALL non-Pro, non-admin users. This gives every free user a fresh start with 25 prompts. Use during promotions or after pushing trial limit changes.
📥 Export Full User Database
Downloads a CSV file of all users with their UID, email, country, language, trial usage, and Pro status. Useful for analytics and backups.
🏗️ Reset Admin Trial (Self)
Uses the /api/admin-reset endpoint to reset your own account's trial counter and set isPro=true. Run this if your dev usage inflated the counter.
